STEP 1 · MODEL CONNECTION

Connect the AI service you want AgentMesh to use

Create a provider for a cloud API or a local model server. After creating it, save its API key from the provider row, then test the connection after adding at least one enabled model.

  1. 1
    Create provider

    Choose the API format, give it a recognizable name, and enter the service base URL when required. For Ollama, use your local Ollama endpoint. The API key environment variable field is optional.

  2. 2
    Save the API key

    After the provider appears in the table, use the “New API key” field and “Save key” button in that provider row. AgentMesh stores the key securely and never displays it again. Local providers such as Ollama may not need a key.

  3. 3
    Add and enable a model

    Open Models and enter the model ID expected by your provider. Then return here and test the connection.

STEP 2 · MODEL SELECTION

Tell AgentMesh which model to call

A model entry connects a provider to the exact model name accepted by that API. The Model ID is an internal unique ID; API model name is sent to the provider (for example, the model name shown in your provider console). Enable the model after saving it.

Tip: use a short stable Model ID such as my-provider-main, and keep API model name exactly as documented by your provider.

STEP 3 · FIRST AGENT

Create an Agent, then give it one small task

An Agent definition is the reusable configuration: choose a model, describe its role in the system prompt, and save it. Then use the Run agent form on that Agent to submit a task.

  1. 1
    Create an Agent definition

    Give it a unique ID, a name, the enabled Model ID, and a clear system prompt. You can leave approved tools empty for a simple text-only task.

  2. 2
    Choose a workspace

    Select an existing workspace when running the task. The workspace is where the Agent keeps its task context and files.

  3. 3
    Start with a small prompt

    For example: “Summarize the purpose of this workspace and list three next steps.” Open the resulting Execution to inspect what happened.
